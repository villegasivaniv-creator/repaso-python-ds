# Repaso de Python Básico para Data Science

## Descripción

Este repositorio contiene una práctica de repaso de fundamentos de Python,
pensada para consolidar el manejo de datos básicos **antes** de avanzar
hacia librerías de alto nivel como Pandas o Scikit-Learn.

El archivo principal es `practica_python.py`, e incluye:

1. **Definición de variables**: uso de tipos de datos básicos (`str`,
   `float`, `int`, `bool`) e impresión de un resumen con f-strings.
2. **Lógica de negocio (bucle + condicional)**: recorrido de una lista de
   precios clasificando cada uno como "Caro" o "Económico".
3. **Estructura de datos compleja**: manejo de un diccionario (`almacen`)
   que representa productos y su stock, agregando y consultando datos.
4. **Modularización con funciones**: una función `resumen_estadistico`
   que recibe una lista de números y devuelve un diccionario con la suma
   total, el promedio y la cantidad de elementos.

## Cómo ejecutarlo

```bash
python practica_python.py
```

No requiere dependencias externas, solo Python 3.
